Generated by `npm run legacy:csv` (`scripts/legacy/generate-unit-b-export.ts`). Fictitious data. Do not edit by hand: change the generator and run it again.

- The export date comes from the file name (`unit_b_export_YYYY-MM-DD.csv`). Under BR10 each file is a full snapshot from 2026-01-01 up to its export date.
- One row per invoice line. Columns: `INV_NO, CUST_NAME, INV_DATE, CURRENCY, LINE_ITEM, QTY, UNIT_PRICE, INV_TOTAL`. `INV_DATE` is `MM/DD/YYYY`. `CUST_NAME`, `INV_DATE`, `CURRENCY` and `INV_TOTAL` repeat on every row of an invoice. `UNIT_PRICE` and `INV_TOTAL` have 2 decimals.
- The main export has 78 valid invoices, totalling USD 109915.83.
- Line endings are LF. Fields that contain a comma are quoted (`"Cedar Valley Bakery, Inc."`); that is correct CSV, not an error.

## Snapshot sequence (AC17)

Upload the files one at a time, in this order, and wait until each one is ingested. `legacy-ingest` takes the oldest new export date first, so uploading them together would ingest the 10-15 file before the 10-16 one.

1. **`data/unit_b_export_2026-10-16.csv`:** the baseline. Expect the outcomes above.
2. **`data/unit_b_export_2026-10-17.csv`:** identical except that two invoices are missing:
   - UB-26001 (Lakeside Deli Company, 01/07/2026, USD 882.00, valid) leaves the figures, and Lakeside Deli Co.'s Unit B total drops by USD 882.00.
   - UB-26010 (Lakeside Deli Company, in quarantine as `INVALID_DATE`) gets its quarantine entry closed, with resolution `removed_from_export`. It was never in the figures, so no total changes.
   - Every other invoice and every other quarantine entry stays as it was.
   - Both removed invoices are outside April to September, so no expected trend changes (the generator checks this).
3. **`data/unit_b_export_2026-10-15.csv`:** its export date is older than the newest ingested one (2026-10-17), so the whole file is rejected and nothing changes.
   - It is a real older snapshot: it lacks the 3 invoices dated 10/15/2026 (UB-26083, UB-26084, UB-26085).
   - If it were wrongly accepted, those invoices would leave the figures or the quarantine, which makes the failure visible.
